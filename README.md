# Project Iron

> "녹슨 철로 거짓 신에 맞서라"

2D 전략 디펜스 게임 - Phaser 3 + TypeScript

## 게임 소개

인류 저항군의 지휘관이 되어 외계 침략자 "아스테리온"에 맞서 기지를 방어하세요.

- **장르**: 2D 전략 디펜스 + 유닛 커스터마이징
- **시점**: 쿼터뷰 (아이소메트릭)
- **아트**: 픽셀 아트 (32×32)

## 빠른 시작

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 http://localhost:3000 접속

## 조작법

| 버튼 | 설명 |
|------|------|
| 광산 일꾼 | 광물 수집 (8/초) |
| 발전기 일꾼 | 에너지 수집 (5/초) |
| 전투 유닛 | 적과 싸우는 유닛 생산 |

## 게임 규칙

- 일꾼을 생산하여 자원 수집
- 전투 유닛으로 적 웨이브 방어
- 기지 HP가 0이 되면 게임 오버

## 기술 스택

- **엔진**: Phaser 3
- **언어**: TypeScript
- **빌드**: Vite
