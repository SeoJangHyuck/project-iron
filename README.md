# Project Iron

> "녹슨 철로 거짓 신에 맞서라"

2D 전략 디펜스 게임 - Phaser 3 + TypeScript

## 게임 소개

인류 저항군의 지휘관이 되어 외계 침략자 "아스테리온"에 맞서 기지를 방어하세요.

- **장르**: 2D 전략 디펜스 + 유닛 커스터마이징
- **시점**: 쿼터뷰 (아이소메트릭)
- **아트**: 픽셀 아트 (32×32)

## 세계관

**인류 저항군 "이단자"** vs **외계 침략자 "아스테리온"**

아스테리온은 신을 자처하며 인류를 지배하려 했다. 그들의 "구원"이 예속임을 깨달은 자들이 저항군을 결성했다. 플레이어는 녹슨 기계로 빛나는 거짓 신에 맞선다.

## 핵심 시스템

### 3파츠 조합 (개발 예정)
| 파츠 | 역할 |
|------|------|
| 다리 | 이동속도, 하중 |
| 몸통 | HP, 무기 타입 |
| 팔 | 공격력, 사거리 |

### 자원 시스템
| 자원 | 용도 |
|------|------|
| 광물 | 유닛/일꾼 생산 |
| 에너지 | 기지 스킬 사용 |

### 레인 시스템 (개발 예정)
- 1~3개 레인에서 동시 방어
- 레인별 유닛 배치 전략

## 빠른 시작

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 http://localhost:3000 접속

## 조작법

| 버튼 | 설명 |
|------|------|
| 광산 일꾼 | 광물 수집 (8/초) |
| 발전기 일꾼 | 에너지 수집 (5/초) |
| 전투 유닛 | 적과 싸우는 유닛 생산 |

## 게임 규칙

- 일꾼을 생산하여 자원 수집
- 전투 유닛으로 적 웨이브 방어
- 기지 HP가 0이 되면 게임 오버

## 기술 스택

- **엔진**: Phaser 3
- **언어**: TypeScript
- **빌드**: Vite
